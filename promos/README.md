# Plugin Store promo images

Marketing images for the Joan listing on the Craft Plugin Store, rendered in the same theme as
the plugin's marketing page at
[justinholt.com/plugins/craft-joan](https://justinholt.com/plugins/craft-joan).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `joan-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp).

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin site's: accent `#AD2324`, Jersey 20 for display, Inter for body.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — the silhouette with the tile stripped. The tile's rounded edge reads as a
  hard box across the slide at watermark scale, which is why the tile goes rather than the
  opacity dropping further. Note the opacity is `0.02`, not the `0.05` the rest of the family
  uses: a solid figure carries far more ink than linework does at the same value.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.

## Screenshots

`shots/` holds control-panel captures at 1274 CSS px wide, taken at 2× from the
`plugin-testing` harness with the CP chrome, the other plugins' panels and the trial footer
hidden. The capture script is not checked in; the recipe is:

- hide `#global-sidebar`, `#global-header`, `#global-footer` and any other plugin's fixed panels,
- set `#page-container { margin-left: 0; width: 100% }`,
- clip to `#main-container`, which keeps the page heading above the panel.

A tall capture gets `class="cpc-frame cpc-clip"` on the slide, which anchors it to its top and
fades the cut — the interesting rows are always the first ones.

## Traps

- **`.points li` is a flex row.** An inline `<span>` inside one becomes a third flex item and
  breaks the sentence into columns. Wrap the whole text in one `<span>`.
- **Don't use `white-space: pre` in `.term`.** The markup's own indentation becomes layout and
  the terminal bursts out of its frame. Align the columns with the fixed-width `<i>` label
  instead, and widen it per slide when a label overflows.
